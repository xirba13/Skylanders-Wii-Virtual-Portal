# Wii U vWii installation

The accepted release is tested on a European Wii U in vWii, slot 252. Use **Skylanders Portal - vWii ONLY**, folder `apps/skylanders-portal-installer-vwii`, group **Skylanders**, base **57 v6175**, destination **252**. The tested installer has no revision selection screen. Never install these platform files on an original Wii.

The complete, current [README installation guide](../README.md#installation) covers SD preparation, all five game patches, USBLoaderGX settings, controls and manual saves. The separate [Wii-only guide](../installer/wii/README.md) uses base 57 v5918 and revision 21999.

Older private cards used the folder `skylanders-portal-installer`; only the folder and displayed metadata were renamed. The accepted runtime modules and game patches were not changed. Old recovery packages and manifests are historical snapshots, not the current release instructions.
